# 検証記録

対象：Jev Dataset Studio 初回実装。検証日：2026-11-25（JST）。

## ローカルで確認したこと

- Python 3.12.14、SQLite、`requirements.lock` の依存パッケージで実行。
- 型・抽出・HTTPフィクスチャ・API・ワーカー・レビュー・出力のテストを実行。
- Ruff、JavaScriptの構文検査、Pythonパッケージのインストールを確認。
- 実際のHTTPサーバーとローカルワーカーで、サンプル投入→全件処理→出力ZIP取得を確認。
- Unicode位置、API失敗と否定の区別、レシピ固定、ワークスペース分離、古いリースの拒否、再開、レビューの版競合、出力の不変性、グループ分割を検査。

## GitHub Actionsの検証

`.github/workflows/ci.yml` は次を実行します。実際の実行結果は [Actions](https://github.com/Unjuno/jev-dataset-studio/actions) の対象コミットを参照してください。

- PythonテストとPostgreSQLによる並列ワーカー検証。
- Docker Composeの設定検査、イメージ作成、Web・DB・ワーカーの起動、出力ZIPまでの操作。
- Chromiumによるブラウザ操作：サンプル、プレビュー、設定保存、ジョブ、確認・修正、ZIPダウンロード。
- HTMLを含む入力を文字列として描画すること、絵文字と結合文字を含む原文位置、モバイルの横はみ出し。
- デスクトップ・モバイルのスクリーンショットを `browser-evidence` artifactに保存。

ローカル作業環境にはDocker/PostgreSQLがなく、Chromiumに必要なUnixソケット権限も許可されませんでした。このため、それらの実行検証をCIに分けています。静的チェックだけで実ブラウザ検証済みとは扱いません。

## 実施していないこと

実際のJev APIキーや検証器のキーを使う有料リクエストは実施していません。HTTP形式はフィクスチャで検証しました。実APIの精度・校正・遅延・請求額・任意の別モデルサービスとの互換性は未検証です。デモデータの結果からこれらを推定しません。

大規模処理のベンチマークや、外部公開サービスとしての負荷・侵入テストも実施していません。25,000行などの入力上限は、測定された性能保証ではありません。
